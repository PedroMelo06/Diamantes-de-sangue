# 💎 Diamantes de Sangue

## 📌 Descrição

Este projeto é um site estático desenvolvido como parte da disciplina de Desenvolvimento Front-end. O objetivo principal é informar e conscientizar sobre o tema **diamantes de sangue**, explicando o que são, seus impactos sociais e políticos, e como ocorrem as ações ilegais relacionadas à sua extração e comércio.

O site apresenta um conteúdo informativo, com layout simples e direto, desenvolvido com HTML e CSS, abordando também iniciativas para combater essa prática.

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3

---

## 📱 Funcionalidades

- Página com introdução ao tema;
- Seções explicativas:
  - O que são diamantes de sangue;
  - Como ocorrem as extrações ilegais;
  - Consequências sociais e políticas;
  - Ações de combate e conscientização;
- Estrutura simples e organizada;
- Layout limpo com destaque para o conteúdo textual.
